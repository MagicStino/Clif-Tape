# Clif Tape

![Clif Tape — stereo tape effect](github-cover.png)

**Tape colour, pitch drift and worn-media textures for Force / MPC.** Clif Tape is a stereo insert effect with large touchscreen controls, white knobs, Q-Links and fifteen ready-to-use presets.

[Download the ready-built installer](https://github.com/MagicStino/Clif-Tape/releases/download/v0.2.0/Clif-Tape-0.2.0-mpc-armv7.zip) · [Usage guide](USAGE.md) · [Presets](PRESETS.md)

Install from the OpenPlugin catalog, or extract the ZIP and run its included installer. No compiling or additional sound files required. The package includes artwork, presets and an uninstaller.

- **Tape:** Off plus twelve selectable tone profiles, Saturate, Failure and Crackle.
- **Digital:** Low-pass, High-pass and DEGRADE for progressively reduced bandwidth and sample rate.
- **Motion:** Wow, Flutter, Spread and Mono to Stereo.
- **Tape Noise:** independent Noise and Mechanical switches and levels.
- **Silence Gate:** automatically fades Crackle, Noise and Mechanical together when the input becomes silent.
- **Mix:** starts at 40% wet. Every page keeps Mix and Volume in reach.

![Tape controls](preview-0.png)

**Compatibility:** ARMv7 Force / MPC community plugin hosts with OS 3.x skins; tested during development on Force 3.10.0. Windows/macOS VST builds and Gen2/aarch64 builds are not included. The effect reports approximately 8 ms latency.

Source is included in [Clif-Tape-source-0.2.0.zip](Clif-Tape-source-0.2.0.zip); see [BUILD.md](BUILD.md) for developer instructions. Installing the plugin does not require the source package.

See [INSTALL.md](INSTALL.md) for installation, migration and removal. Save your project before installing: the music application restarts.
