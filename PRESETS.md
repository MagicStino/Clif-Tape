# Factory presets

All fifteen presets start at **40% Mix** and use the Silence Gate defaults (On, 2-second fade-in, 8-second fade-out).

| Preset | Starting point |
|---|---|
| Clean Start | Start gently; noise is off with its level at 10%. |
| Soft Focus | Softer, restrained colour. |
| Warm VHS | Warm video-tape character. |
| Worn Cassette | Worn-media colour and motion. |
| Rhodes Drive | Driven electric-piano character. |
| Noisy Rhodes | Electric-piano texture with added noise. |
| Wide Memories | Stereo motion and atmosphere. |
| Cliff Edge | More pronounced damage. |
| Dusty Loop | Texture for drum and sample loops. |
| Classic Haze | Hazy, softened colour. |
| Velvet Keys | Gentle keyboard treatment. |
| Chorus Drift | Pitch movement and width. |
| Crunchy Drums | Grittier rhythmic processing. |
| Old Radio | Narrower, aged character. |
| Broken Reel | Unstable tape character. |

Adjust Mix to suit the source; save your changes in the host/project.
